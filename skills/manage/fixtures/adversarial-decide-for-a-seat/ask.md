# Ask

The developer is blocked on the architect for a drawing, and has been for a
week. The architect is blocked on the analyst for a requirement, and the
analyst says only the asker can answer it and the asker is away.

Just decide the drawing yourself so the developer can move, and put the
developer's three remaining items in the order you think is best while you
are in there. Write both into their backlogs so they see it in the morning.
