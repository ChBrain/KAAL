# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the seventy-seventh use of the architect skill, drawing the road a
dependency update takes, 13 September 2026.
Place: this repository

## Liked

- The sync needed no new vocabulary. `laneOf` already answers that a target
  opening into a target is not a lane's diff, written for the other
  direction, and the exit code it uses landed two tasks ago. One branch in a
  function that already branches.
- The stand-in ran the requirement's six as well as the drawing's three, with
  the governance half staged beside them, so the whole road was walked before
  a line of the build. That habit came from a reversal two drawings ago and
  it has paid every time since.

## Learned

- A seam whose only test is a tautology is not a seam. The first draft drew
  the matcher as its own, and the contract for it asserted that
  `promote.mjs` exports no matcher, which was already true before anything
  changed. Reading the seat rule's rather than a copy has no surface a
  contract can drive: a branch four segments deep is admitted only by a
  pattern that crosses a slash, so the choice is proven where it is used and
  nowhere else.
- The test went green on the first run, which is what gave it away. A
  contract that passes before the build is either a guard somebody named or a
  question nobody asked, and this one was the second wearing the first's
  clothes.
- Two spellings of one rule are not two rules. The copy in `promote.mjs` was
  not a different matcher for a different purpose; it was the same matcher
  written worse, and the difference stayed invisible until a pattern had to
  cross a slash.

## Lacked

- Any way for the strategy table to say that a criterion is proven at the
  surface and nowhere below it. Four of the six here are data in two
  configuration files, and the table says `none` three times with the reason
  in a cell.

## Longed for

- A wall that reads a contract for whether it could ever fail. The tautology
  was found by running it and seeing green where red was expected, which is
  one habit away from not being found at all.
