# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the seventh use of the manage skill, reconciling the 0.0.2 plan
against live pull request state after a supervisor blocked the diff this plan
had called mostly paid, 14 September 2026.
Place: this repository

## Liked

- Reading the review rather than the pull request body found the block. The
  body and a later comment both read as progress; the review said blocked with
  changes required, and only one of the three was the state.
- The asker's correction arrived as four specific edits rather than a verdict,
  which made each one checkable against the tree.

## Learned

- A plan said an architecture cost was mostly paid on the strength of a diff's
  own summary of itself. A diff is not a witness to its own readiness, and the
  seat that reviewed it was the one holding the fact.
- The same sentence then sequenced a developer behind that drawing. Ordering a
  downstream seat behind a blocked upstream one is how a seam gets built twice,
  and the plan had no reason to name the seat at all.
- A superseded section left in place for its decision kept asserting live state
  around that decision: two merged pull requests described as open, a
  cross-seat order replaced twice over, and a board four revisions old. History
  is worth keeping and stale live state inside it is not, so the two have to be
  separated where the section sits rather than remembered by the reader.
- A block can point back up the chain rather than down it. The supervisor
  offered a root of trust or an amendment to the requirement, and the second is
  the architect returning the criterion to the analyst as undrawable as
  written, which is a live edge of the dependency table this plan carries and
  had never been recorded against a real task.

## Lacked

- Any surface that tells a manager a pull request is blocked. The plan reads
  boards, backlogs and diffs; the block existed only in a review, and nothing
  in the tree reads those.
- A way to tell a draft from a ready lane without asking the host, which is
  what the accepted lifecycle requirement is for and why it is still red.

## Longed for

- A cost that is known to be unknown, rather than an estimate inherited from
  the party being estimated.
- The dependency table's return edges exercised on real work, so an architect
  handing a criterion back to an analyst is an ordinary move rather than a
  thing this file had to argue for the first time.
