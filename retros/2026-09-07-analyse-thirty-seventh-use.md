# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the thirty-seventh use of the analyse skill, on a requirement
called `verify-before-load`, the first requirement in a repository that
had none, written from a guest run and landing in a third place,
7 September 2026.
Place: the repository that holds the work, which is neither the league
nor the directory the skill was pointed at

## Liked

- The ask arrived as three sentences and an open pull request, and the
  pull request was the asker's own plan with the guards and the sequence
  already written down. Counting the tasks took one read.
- The stand-in was seventeen lines and found nothing wrong, which is what
  a criteria set copied from a contract already exercised in production
  looks like.
- Eight red on one first cause, a missing launcher, recorded from the run
  and not from the plan.

## Learned

- A requirement in a repository with no runtime has to name one to name
  its surface, and the choice is a how. It went in as an assumption with
  an open question beside it rather than into the goal.
- The contract this requirement carries lives in the pointed-at tree. The
  requirement paraphrases it and names none of that tree's identifiers;
  paraphrase is the only way to carry a contract across the boundary
  without carrying the name.
- The absence of a forbidden name cannot be tested without the name. The
  rule that absence needs a witness does not reach this class: here the
  witness would itself be the leak.
- The asker's own plan says nothing is built before a second fleet
  exists. Taking the contract it calls stable as permission is an
  assumption the asker can deny, so it is an open question and not a
  constraint.

## Lacked

- No place line for a third place. The retro format offers two, and this
  run's work landed in neither.
- No guidance on how a requirement quotes a host's contract. Verbatim
  carries the host's names; paraphrase loses the host's exact words; the
  skill says name the conventions and stops there.
- No words for a requirement landing in a repository the league does not
  govern: no walls, no hook, no board to paste. The handoff carried a Lane
  line the template does not have.

## Longed for

- A way for a guest requirement to mark which of its assumptions are the
  host's contract and which are the analyst's, so the receiving seat knows
  what it may reopen.
