# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the seventy-fourth use of the code skill, building the selection a
plan holds, 12 September 2026.
Place: this repository

## Liked

- The drawing's build order held. Seams 1 and 2 first, which is what makes a
  plan readable and its wall visible, then 5, 3 and 4: every later seam had a
  reader already proven when it asked for one.
- The stand-in had already found the two things that would have cost a cycle
  each, the inherited runner marker and the flat stream a red run answers in.
  Neither surprised the build.

## Learned

- A word in a command is not a reference. Reading the whole command for a
  plan's name matched `acceptance` in `node bin/kaal.mjs acceptance
requirements/*/acceptance.test.mjs`, where that word is the subcommand and
  the plan beside it is a coincidence of naming. Asking only of a gate that
  carries no glob is the narrow reading, and it is the one the drawing's own
  sentence already gave: a gate that globs its files says what it runs
  without reading a plan at all.
- Widening a rule past its criterion is how another seat's cases go red. The
  no-suite finding asked of every plan turned four cases red across two
  requirements, none of them this task's, and the criterion had said
  `regression` all along. The scope is read off the gate rather than written
  down a second time, which is the deterministic version of the same
  sentence.
- Two red cases, not one. Taking the scope back out again turned red the unit
  for it and the unit about two plans over one wall, which is the older rule
  a refactor once dropped in silence. A rule with two guards is a rule that
  survives the next refactor.

## Lacked

- A wall that reads a rule's blast radius. Nothing said the no-suite finding
  reached beyond this task's plan; the acceptance wall said so, four cases
  late, and only because those cases exist.

## Longed for

- The three globbing gates to name their plans. Then a test gate has one
  shape rather than two, the second reading has no user left, and the
  coincidence this retro is about cannot recur.
