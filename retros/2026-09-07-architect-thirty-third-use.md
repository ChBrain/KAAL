# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the thirty-third use of the architect skill, on
`architecture/pointed-elsewhere` (three seams: a fixture that ships a
tree, a procedure for the person, and a record that says whether the tree
moved), 7 September 2026.
Place: this repository

## Liked

- The skill's new rule earned itself within the hour. Reading the closed
  tests as well as the closed criteria is what found `eval-record-v1`
  iterating its ten fields, which killed the simple answer of an eleventh
  field before I had written a line of it.
- Deciding that the procedure belongs in the page's header and never
  inside a prompt. Prompt one is pasted into a model, and a model told to
  copy a tree and run a witness would try; the copying and the verdict are
  the person's acts.

## Learned

- The stand-in found a second closed task the reading had missed.
  `evals-v2` derives the evals workflow's record template from exactly the
  field bullets in `evals/README.md`, so documenting a new field in that
  list demands an unattended workflow write a verdict about a filesystem
  it never touches. The criterion gave way: the field is documented in its
  own section instead, and the requirement, the drawing and this retro all
  say why.
- Two closed tasks pushed on this drawing from different directions, one
  found by reading and one by running. Reading is cheaper and it is not
  enough.

## Lacked

- The skill says to read the closed requirements' tests, which I did, and
  it does not say how far. `evals-v2` is a task about a workflow, and its
  contract reaches a documentation page I was editing for a different
  reason. Nothing suggests reading the tests of tasks that touch the same
  file for unrelated purposes.
- No guidance on amending an open requirement's criterion from this seat.
  The precedent here is to amend and record, and it is precedent, not a
  rule.

## Longed for

- The reading three seats have now asked for, from a fourth angle: given a
  file I am about to edit, which closed tests read it. Twice today that
  question had an answer I only found by running.
