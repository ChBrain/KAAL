# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the eighty-first use of the architect skill, redrawing the trust
boundary of `an-open-finding-blocks-every-target` after a supervisor review
refuted the eightieth, 14 September 2026.
Place: this repository

## Liked

- The review named one thing and it was the right thing. Not a list of
  smaller findings: one question, asked so that answering it honestly could
  only end in a redesign or a refusal. The cheapest way to read it was to try
  to defeat it, and the attempt took forty lines.
- Writing the forgery before writing the fix. The script that made the old
  wall exit 0 is the same script that now answers `unattested evidence`, so
  the refutation and the proof are the same artefact run twice.
- The residual came out of the same exercise rather than out of modesty. Once
  a key holds the seal, the question "who can still lie" has a real answer,
  and it names a lane and a merge instead of a feeling.

## Learned

- **The seam I drew as the strong one was the one the review broke.** The
  eightieth use spent its whole budget making the candidate binding exact:
  every file, a digest, four states for a mismatch. All of it correct, and all
  of it about the same document the adversary writes. A design can be made
  arbitrarily precise on the wrong side of a boundary and feel like progress
  the whole way.
- Stand-ins do not test trust. Mine ran the layer above and answered fourteen
  passing, because every acceptance case handed the wall evidence I had
  written myself. The suite could not have caught this and neither could any
  wall in the tree: the missing case was one nobody had thought to write, and
  a reviewer thought of it.
- **My own drawing said it out loud and I did not hear it.** The first
  revision's decision records contain the phrases "three fields a producer
  must set honestly" and "one more field the producer must not lie in". That
  is the finding, written by me, filed under Bought as though naming a cost
  discharged it. A cost named and not priced is a hole with a label on it.
- A signature over bytes would have been broken by our own formatter within a
  day. Signing a canonical reading instead is four lines and makes the seal
  survive `prettier --write`, which is the difference between a control and a
  ceremony somebody disables.
- Excluding a whole directory because one file in it must be excluded cost
  something real. Narrowing the skip to the evidence file alone pulled the
  trust anchor inside the candidate, so rotating the root of trust now forces
  re-gathering instead of silently re-blessing old evidence. The better
  boundary was one character of precision away the first time.

## Lacked

- Any way for a wall in this tree to ask "could the party this evidence is
  about have written it". Every wall here reads content, and content is
  exactly what a self-asserting producer controls. This is the first artefact
  in the league that needed a key, and nothing before it had raised the
  question.
- A block kind for a control only a person can create. The delivery of this
  task now waits on a signing key, and the four kinds are `no requirement`,
  `no drawing`, `no proof` and `no record`. I wrote no block rather than a
  false one, and that is the second retro running where the backlog could not
  carry the thing this seat actually knew.

## Longed for

- A review like this one earlier in the cycle. It arrived after a pull request
  that pasted a green CI run over the work, and every hour between the two was
  spent on downstream handoffs that were premature. An adversarial reading of
  the seams, before the fixtures were built, would have cost one hour and
  saved four.
- A habit the skill enforces: for every field the drawing says somebody must
  set honestly, write the case where they do not. That sentence appeared twice
  in the refuted drawing and neither time did it become a test.
