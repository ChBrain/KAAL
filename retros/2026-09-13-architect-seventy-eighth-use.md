# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the seventy-eighth use of the architect skill, drawing how a refusal
names whose path it reached, 13 September 2026.
Place: this repository

## Liked

- The runs answered the whole page before a decision was written. The owner
  is a local variable in one loop, two things call the function, one of them
  is a closed proof that reads the finding by substring and pins nothing
  whole. That is the shape of the task and the size of the risk in two
  sentences, and neither is a claim.
- Three seams, three contracts, each red on its own, and the stand-in green
  on all three plus the requirement's five plus twenty-four in the closed
  tasks that read this line. Nothing had to be guessed about the blast
  radius, because the blast radius was measured first.

## Learned

- **The seam that could not be driven was the one worth checking.** Seam 3
  says a branch no lane holds gets no block, and that is true today for a
  reason that has nothing to do with this task: the command never calls the
  function on that branch. A contract asserting only that would have passed
  before the build and proved nothing, which is exactly the tautology this
  release met a week of work ago. It is folded into the seam that also drives
  the positive half, so the test is red now and the negative half is still
  held.
- A pin is not always the whole file, and the wall says which part moved. The
  drawing's requirement pin is the sha of the requirement's Acceptance
  criteria and not of `requirement.md`, and `traces --write` does not write a
  pin an artefact declares about another. The first attempt pinned the file,
  the wall said the Acceptance criteria no longer matches, and the word
  `region` in `traces.mjs` is where that is decided.
- Two refusals with an owner are not one rule. A path outside the lane and a
  proof another seat wrote both refuse and both know whose it is, and the way
  through them is different: a message for the first and a supersede for the
  second. The drawing that treated them together would have enlarged the task
  without the asker, and saying so in a decision costs one paragraph.

## Lacked

- Anything that computes a pin an artefact declares about another artefact.
  `traces --write` fixed the suite pins in one command and left the drawing's
  requirement pin to be written by hand from a function call.

## Longed for

- A suite that names its cases by reading the tree. Adding one contract moved
  the contracts suite, which moved the plan that names it, which is the third
  time in one day that a case being born rippled into two other seats' pages.
