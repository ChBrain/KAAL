# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the eighty-second use of the analyse skill, correcting the fixture
under criterion 5 of `a-suite-names-its-cases`, 11 September 2026.
Place: this repository

## Liked

- The criterion was right and only its proof was wrong, which is the cheap
  half of this to find. The page says one suite traced by two plans is not a
  finding; the fixture gave the two plans one wall as well, and that is a
  different cardinality that this very page says still stands.
- The guard named the crossing before the board did. The branch was one word
  short of the task it edits and the seats wall refused it, so the rename was
  the whole cost of a rule that exists to stop one analyst diff rewriting
  another task's criteria.

## Learned

- A proof that needs a rule to be absent is a proof of the absence. This
  fixture has been green since the rule that contradicts it was dropped from
  the board, and green is exactly what it would say either way. Nothing in the
  tree distinguishes a case that passes because the tree is right from one
  that passes because the tree forgot.
- A superseding requirement carries the surviving criteria of what it
  supersedes, and it says so in prose, in the handoff, where no wall reads it.
  This diff only found the contradiction because a person went looking. The
  four criteria named as standing are a list a wall could hold.

## Lacked

- Any tie from a criterion that stands to the fixtures written after it. The
  handoff names four criteria of another task as surviving, and a new case in
  this task contradicted one of them on its first day.

## Longed for

- A fixture that declares which cardinality it is about, so a second one
  sharing the tree by accident is a finding rather than a coincidence.
