# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the sixty-eighth use of the code skill, making a wall read the base
its diff is actually against, 11 September 2026.
Place: this repository

## Liked

- The first diff that used what the shared suite bought. A new unit beside its
  module and the line naming it in `tests/suites/units.md`, one lane, no
  second diff, no block. Yesterday this was impossible.
- The bug was found by the branch itself. `release` appeared, the next pull
  request into it went red on the seat rule, and the cause was a constant.

## Learned

- A second target makes every fixed base wrong. `origin/main` was hard coded
  and correct while there was one place to open into. The hour `release`
  existed it began showing a lane branch every other seat's merged work and
  calling it many lanes, which is the wall doing its job on the wrong
  question.
- The order of the fallback is the design. A branch is likelier to have come
  from `release` than from `main` now, and a clone that has fetched neither is
  a clone that can be told the question is not its. Naming the environment
  first is what lets a gate say the pull request's own base rather than have
  the tree guess at it.
- The local hook does not know about the second target either. It refuses a
  red board on any branch, so a wall standing red on `release`, which is the
  whole of what the release branch is for, cannot be pushed at all. The rule
  is written on the pages and enforced nowhere yet, and the enforcement that
  does exist is the strict one applied everywhere.

## Lacked

- A name for the constant that is still true. `DEFAULT_BASE` now means the
  last resort and reads like the ordinary case. Renaming it needs the unit in
  `tests/class.test.mjs` to move beside this module first, which is another
  seat's lane and the next item in the plan.

## Longed for

- One place that says what a target is. Two lists now name `release` and
  `main`, one in this module and one in a workflow, and a third is coming in
  the promotion.
