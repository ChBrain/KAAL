# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the ninth use of the test skill, recording the two runs that make the
first promotion clean, 12 September 2026.
Place: this repository

## Liked

- `promote: into main: nothing refuses this`. Every verdict on record, no wall
  red, and the head rule satisfied. The gate this release is built around has
  nothing to say about the tree it is built in, which is the first time that
  sentence has been true.
- Two records and both were owed. `push-v1` because two models read a fixture
  this morning; `status-v1` because its fourth case moved onto fixed ground an
  hour ago and the record pinned the suite before that.

## Learned

- The first red wall on `release` was an accident, not a decision. The format
  wall went red because a retro written in the same command as its commit was
  never formatted, and the hook let the push through: a lane branch is judged
  toward `release` now, and toward `release` a red wall is reported rather
  than refused. The old hook would have refused that push. The new one did
  what it was built to do, and the first thing it did with the freedom was
  carry an unformatted file onto the target.
- That is the cost of the rule and it is worth paying, but it is not free and
  it should not be discovered later. A wall red on `release` is a block with
  an owner; this one had an owner for forty minutes and nobody knew, because
  nothing announced it between the merge and the next person to run the board.
- Writing a file after the last board run is how it happens. The retro, the
  format, and the commit were one command, and the board had already answered
  about a tree that did not yet hold the retro.

## Lacked

- Anything that says `release` is red. The promotion says so when somebody
  asks for a promotion, and until then the target's own colour is a thing you
  find out by running the board yourself.

## Longed for

- The board run after the file is written and not before, which is a habit and
  not a wall, and habits are what this league keeps replacing with walls.
