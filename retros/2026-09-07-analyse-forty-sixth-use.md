# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the forty-sixth use of the analyse skill, on
`requirements/a-requirement-shows-its-work`, a run over a stack of twelve,
7 September 2026.
Place: this repository

## Liked

- The loudest item needed no judgement. Six of the twelve name the same
  missing place and four of them count the streak out loud, so the first
  criterion wrote itself and the only work was deciding what the section is
  called. A stack that argues with itself would have been harder and this
  one did not.
- Writing the new section into this requirement before asking for it. The
  runs that decided this task are on its own page under the heading it
  demands, which is the cheapest possible argument that the heading is
  worth having.

## Learned

- Two of five tests were green for the wrong reason and only a run found
  each. The first passed against the unchanged tree because folding the
  template put every heading on one line; the second passed with the new
  rule deleted, because the section already said "run" and "assumption" for
  other reasons. The fix was to tie the two documents by the heading's own
  words, which is the pattern the surface page and the usage line already
  use.
- The isolation is what found the second one. Four of five partial
  stand-ins reddened a test and the fifth reddened nothing, which is not a
  pass, it is a test that is not holding its half. That is the rule this
  task adds, found while adding it.
- A stack carries items that are not the skill's. The retro name being a
  race cost three files and a merge today and belongs to a wall or to
  `retro-4ls`; the runtime matrix is governance. Naming them in the
  assumptions is the only way they survive being out of scope.

## Lacked

- Nothing says what a run over a stack does with items it cannot take.
  Eleven subjects went into six open questions, grouped by hand, and a
  reader has no way to tell which were judged too small from which were
  judged someone else's.
- The ten-retro rule fires per skill and two skills are over the line. The
  rule says when to run and nothing about a second stack waiting behind the
  first, so the architect's eleven are named in an assumption and otherwise
  unattended.

## Longed for

- A way to mark an item as belonging to another skill, so the stack that
  found it and the skill that owns it are both recorded without a task in
  between.
