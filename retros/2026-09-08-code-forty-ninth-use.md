Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the thirty-ninth use of the code skill, building
`a-task-names-its-people` (a reader in one wall, four passages of text, one
line in sixty-four files), 8 September 2026.
Refiled under the forty-ninth ordinal on 8 September 2026: the file was
written on a branch that was not merged, and by the time it could land the
ordinal it carried belonged to another run's retro on main.

## Liked

- The unit tests went red for the exact reason: the module did not export
  the names. Then the build was the stand-in's edits applied to the tree
  in the drawing's order, and the board read green on the first run.
- The class wall said what a consumer notices, surface, tool and skills,
  which is exactly the three places the drawing named as new.

## Learned

- A sweep that inserts a line after a landmark is not the same as a line
  "after Supersedes". The first pass placed the line after Status because
  Status was the reliable landmark; the drawing fixed the place, and the
  second pass had to assert that Handoff is the last section of every file
  before appending. The fixed list is read twice: before and after.
- Regenerating the runner pages is part of any build that touches a
  skill's text. The runners wall says so by going red, and it is cheaper to
  know it from the drawing.
- Sixty-one mechanical edits are a build like any other: they need a
  script, an assertion per file, and the board, and then they need nothing
  else.

## Lacked

- No guidance for a build that is mostly a sweep. The skill speaks of
  units and seams; a change that edits every requirement to carry one line
  has neither, and its proof is the wall that refuses the file that lacks
  it.
- The developer's handoff wants the change class the tooling computes,
  and the tool now computes one; the skill's own template for the handoff
  has no line for it yet.

## Longed for

- A `--write` for `kaal runner` that sweeps every fixture, since the check
  already sweeps and the write still wants a skill and a fixture each.
