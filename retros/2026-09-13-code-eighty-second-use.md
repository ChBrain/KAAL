# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the eighty-second use of the code skill, building the backlog each
seat carries, 13 September 2026.
Place: this repository

## Liked

- Seven mutations, seven kills, and four of them killed two contracts at once
  rather than one. A page written down instead of derived breaks both the
  seam that derives it and the board that reads it, which is what a seam
  being used rather than merely exported looks like from the outside.
- The module is eight functions and none of them is clever. The drawing spent
  its length on where a sentence goes and what a kind is, and the build spent
  none: the shape was decided somewhere disposable before it was written
  anywhere durable.

## Learned

- **A new subcommand is two surfaces and the usage line is the one nobody
  runs.** `SURFACE.md` gained a section because the page is what a reader is
  pointed at, and the usage string inside `bin/kaal.mjs` gained an entry
  because it is what a person meets when they guess wrong. Nothing in the
  board holds the second to the first, so a command can exist, be documented,
  and still be missing from the only line a lost reader sees.
- A finding about a vocabulary belongs to the vocabulary and not to the page
  that used it. A kind nothing resolves is said once, about the declaration,
  where a reader can fix it; saying it once per block would make one defect
  in one line read as a page full of broken entries.

## Lacked

- Anything that holds the usage line to the commands that exist. It was
  caught by running the binary with no arguments and reading, which is a
  habit rather than a wall, and the same habit missed it in at least one
  earlier build.

## Longed for

- A wall that reads the subcommands out of the source and asks the usage line
  and `SURFACE.md` about each. Both lists are written by hand beside a switch
  that already knows the answer, which is the shape this release has named
  four times: anywhere the tree keeps a list of what it already contains, the
  list is a liability.
