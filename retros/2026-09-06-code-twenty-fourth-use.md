`architecture/assess-boundary` (the assessor's first tree, and the wall
that guards it), 6 September 2026.

## Learned

- A unit test for a path rule needs the near miss, not only the hit: a
  sibling directory whose name begins with the target's name is not
  inside the target, and a prefix comparison without the separator would
  have refused it. The test carries that case, and the rule compares with
  the separator.
