# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the sixty-seventh use of the architect skill, excluding a fixture from
seam 8 of `a-suite-names-its-cases` after the first reading of it on this tree
asked for forty six of them, 11 September 2026.
Place: this repository

## Liked

- The number is the argument. Wiring the seam as drawn produced forty six
  findings and every one named a file inside a `fixtures/` directory, which is
  a scratch tree built for a case. Nobody had to decide whether a fixture is a
  case; the tree said what happens if you pretend it might be.
- The distinction was already in the tree. The seats guard's proof table holds
  `requirements/*/fixtures/**` as the analyst's own proof, so a fixture is
  already a thing this league tells apart from a case, and the seam reads that
  rather than inventing it.

## Learned

- Two seams have now gone red after being green, and both for the same kind of
  reason: the promise grew. Seam 7 grew when the criterion it serves widened;
  seam 8 grew when the tree it reads turned out to hold something the promise
  had not considered. A seam list has no way to say either, so the handoff
  says it twice in prose and the list reads as though both had always said
  this.
- A seam is only as good as the first tree it meets. Seam 8 was drawn,
  contracted, stood in and built, and none of that touched a fixture, because
  the contract's fixture had no fixtures in it. The forty six arrived the
  first time it ran anywhere real.

## Lacked

- Nothing in the skill about running a seam against the league's own tree
  before it is built. The stand-in proves a seam can be kept; it says nothing
  about what the seam will find where it is going to live.

## Longed for

- A seam that carries what it excludes, so that the two exclusions in seam 8,
  the unreached tree and the fixture, read as one shape rather than as a rule
  and an afterthought.

Tensions weighed: `the-two-goods`, once. Excluding the fixture buys the
shortest path to a wall that says something true, and spends the option of a
suite ever naming a file inside a fixture, which nothing wants.
