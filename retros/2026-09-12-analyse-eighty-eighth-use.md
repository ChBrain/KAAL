# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the eighty-eighth use of the analyse skill, giving a red case an owner,
12 September 2026.
Place: this repository

## Liked

- The stand-in earned itself for the fourth time. Seven criteria went green
  on a throwaway and it handed the architect four things no amount of reading
  would have produced: that criterion 3 needs the blocked case run, that the
  judged wall's own verdict has to learn about an entry it did not judge,
  that the runner is handed files and never a root, and that the two hard
  criteria together mean the case runs exactly once.
- The fixture taught the shape. A bug page with no frontmatter block turned
  four cases red for a rule this task is not about, which is the tree saying
  a bug is an artefact like the other four kinds before anyone designed one.

## Learned

- A criterion can be redundant against a rule that already exists. Criterion
  4 was first proven with a case file that sat in the tree and no suite
  named, which the suites wall already answers; the criterion said nothing
  the tree did not. Proving it with a path that has no file behind it is the
  half nothing else covers, and it took reading the failure to see that the
  fixture was arguing for a rule already in place.
- A criterion of the ask can collide with a standing rule. `AGENTS.md` says
  never skip, disable or quarantine a test, and criterion 7 stops a wall
  running a case. I think criterion 5 keeps them apart, because a quarantine
  buys a green and this buys nothing, but that is an argument and not a fact,
  so it is the asker's first open question rather than an assumption I made
  quietly.

## Lacked

- Anything that reads a criterion against the closed rules. The collision
  above was found by remembering a sentence, and the tree holds several
  hundred sentences of that kind.

## Longed for

- A way to say that two criteria describe one act from two sides. Three and
  seven are the same run seen twice, and the requirement can only say so in
  prose that no wall reads.
