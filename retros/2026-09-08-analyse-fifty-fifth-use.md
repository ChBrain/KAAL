# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the forty-fifth use of the analyse skill, on
`requirements/a-task-names-its-people` (seven criteria, a standing question
every requirement answers), 8 September 2026.
Refiled under the fifty-fifth ordinal on 8 September 2026: the file was
written on a branch that was not merged, and by the time it could land the
ordinal it carried belonged to another run's retro on main.
Place: this repository

## Liked

- The ask named the shape it wanted, standing, and the tree already had
  the shape for it: one line in the handoff that a wall reads, the way the
  status line is read. The requirement decided almost nothing new.
- The stand-in ran the whole board, not only the seven tests, and the
  board said which closed tasks the change reaches: two fixture
  requirements under a drawing, an orphan drawing that must keep reading
  as no status, and three skills' runner pages. None of that was in the
  plan and all of it was in the run.

## Learned

- A standing requirement is a line every existing task must carry, so its
  build touches sixty-four files to say one word in sixty-three of them.
  That is the cost of "every task answers", and it is the right cost; a
  wall that read only new tasks would pass the old ones for a reason
  nobody can read.
- The asker's word for the thing was a regulation's name, and the league
  cannot carry it: not because a law is a vendor, but because a skill
  written for any tree cannot name one jurisdiction's statute. The
  requirement's opening keeps the word and the skills get the league's.
- A criterion on a section heading breaks the moment the heading gains a
  number. The test read `## Data about a person` and the drawing numbered
  it; the regex now allows a number, which is the analyst reading the
  house convention late.

## Lacked

- No place in the template for a fact established by running something,
  for the seventh retro in a row. The stand-in's board result, which
  decided two criteria's wording, went into the handoff's red run
  paragraph because nowhere else would take it.
- Nothing says the stand-in should run the whole board and not only the
  new tests. This run did it by habit from the day before, and the two
  closed contracts it reached would otherwise have been the developer's
  surprise.

## Longed for

- A rule shared by every seat, written once. This requirement wrote the
  same rule three times in three skills' words, and the drawing priced
  that honestly; the thirty-fifth retro asked for the mechanism and it is
  still not there.
