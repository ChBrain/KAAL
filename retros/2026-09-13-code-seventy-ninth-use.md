# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the seventy-ninth use of the code skill, building what makes a red
case a regression, 13 September 2026.
Place: this repository

## Liked

- Every mutation was killed on the first attempt. Three guards, three
  mutations, three reds, with no unit rewritten after the fact. That is the
  first time today, and the difference is that the units were written against
  the shapes the drawing already named rather than against what the code
  happened to do.
- The wall answered the thing it was built for on the real tree the moment it
  was wired: seventy-one cases reached, three set aside for want of a record,
  exit 0. A wall that has been red on every branch for a day, green and
  saying why.

## Learned

- A new unit file is the one case that costs a diff in another seat's tree.
  `runs.mjs` had no units of its own, so this is a file nobody has named, and
  naming it in `tests/suites/units.md` is the exact shape the asker corrected
  me on earlier: changing a case costs nothing and adding one is a finding.
  The measurement predicted this diff before it happened.
- The join was almost borrowed and the borrow was a cycle. The drawing caught
  it on a stand-in, so the build was five lines and no surprise; without that
  the reader would have answered false for every case and read as a record
  that does not speak, which is an answer this wall gives on purpose.

## Lacked

- Anything that would have told me `runs.mjs` has no unit file. It was found
  by appending to a path that turned out not to exist, which worked, which is
  worse than failing.

## Longed for

- A wall that reads the import graph. The cycle this drawing dodged is a
  silent false at runtime and nothing in this tree would have named it.
