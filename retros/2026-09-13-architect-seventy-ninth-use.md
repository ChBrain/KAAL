# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the seventy-ninth use of the architect skill, drawing how a seat
carries its own backlog, 13 September 2026.
Place: this repository

## Liked

- The tree had the shape already and the page is mostly a citation.
  `traces.mjs` carries a table whose rows say where a thing of a kind lives,
  with a comment explaining why a row per kind is the general form. A block
  waits for a requirement, a drawing, a proof or a record, which are four
  rows that already exist for the same four artefacts. Reading before drawing
  turned a new mechanism into a second reader of an old one.
- Four seams, four contracts, each red on its own, and the stand-in green on
  all four plus the requirement's seven. The whole module is eight functions
  and none of them is clever.

## Learned

- **A criterion's proof fixes shapes the criterion never states, and this
  requirement fixed two.** Criterion 4's test asserts that no `blocked`
  precedes the task's name anywhere in the answer, so the cleared set cannot
  sit after the standing set. Criterion 3's asserts `/\bclear\b/i`, which
  the word `cleared` does not match, so the set is called clear. The first
  was found by reading the test; the second by a stand-in going red on a
  word, after the page had already said the wording was free.
- The free list was wrong until the stand-in ran. It said the wording of both
  sets was the developer's, and one word of it is not. A drawing that fixes
  too little is the same defect as one that fixes too much, and the only
  thing that found it was running the layer above on a throwaway.
- A declared vocabulary needs a wall against itself. The kinds a seat may
  write live in the declaration and where each kind's artefact lives is the
  engine's, which is the split `traces.mjs` already made. What keeps that
  from being two sources of one truth is that a kind the declaration holds
  and the engine cannot resolve is a finding: without it, a kind added by
  hand would make every block naming it stand for ever and nothing would say
  why.

## Lacked

- Any way to know a drawing's free list is honest before the build. Fixed is
  checked by the contracts; free is checked by a developer discovering it was
  not.

## Longed for

- A contract that drives the layer above. The stand-in ran the requirement's
  seven and that is where both shapes were found, and it is a habit rather
  than anything the tree enforces.
