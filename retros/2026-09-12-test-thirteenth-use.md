Period: the thirteenth use of the test skill, recording what the fifth kind

## Liked

- The name of this page was computed and not counted. The script for it is
  not merged yet, so it was read out of its own branch and run against this
  tree, which is the first time a retro's number came from what is on disk
  rather than from somebody's memory of it.
- Both seats are at 68 of 68. Every closed task in this tree is stated by a
  requirement and proved by a run on record, with nothing owed in either
  direction for the first time.

## Learned

- The kind this records is the one that would have carried today's findings.
  Four units were weaker than their comments claimed, a plan page was
  corrupted on every write, and eight cases stood red in CI for days. Every
  one of them was a red with no owner and nowhere to be written down, which
  is the delta the task states, and all four were found by a person looking
  rather than by the tree saying so.
- A record proves its own suite and nothing around it. This page says seven
  cases passed against a sha, and says nothing about the wall that ran them
  or the tree they ran in. That has been true of every record here and it is
  the second time this week it was the tree around the suite that mattered.

## Lacked

- A record that carries the board it was written beside. The verdicts read a
  record against a run and never against the state of the walls, so a suite
  green on a tree with four red walls records exactly what a suite green on a
  clean one does.

## Longed for

- The bugs this kind now holds to be filed by whatever found them. Four
  findings today each needed a person to notice and a person to write the
  page, and the wall that found them already knew the case, the wall, the
  date and, in three of the four, the lane.
