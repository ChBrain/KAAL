# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the forty-fifth use of the architect skill, on
`architecture/a-task-names-its-people` redrawn on the base that merged its
requirement, nine criteria and four seams, 8 September 2026.
Place: this repository

## Liked

- Redrawing on the merged base cost less than the first drawing did, and
  for one reason: every finding the first stand-in's board had made (the
  closed contract on the handoff's order, the orphan drawing's verdict, the
  runner pages) was already in the requirement's What the runs said and
  needed no rediscovery.
- The amendment's two criteria drew themselves: the guest's third kind
  lands in a section a closed contract already fixes, so the seam is that
  contract plus one paragraph, and the test reads the paragraph in the
  section's own terms.
- The stand-in ran on a clone of the branch itself rather than of an older
  tree, so the base it proved against is the base the build will meet.

## Learned

- A drawing on a base that moved is not a rebase of the old drawing. The
  template gained a line between two the old contract read, two skills
  gained paragraphs near where mine go, and the wall's verdict grew a
  case; each was a sentence to check, and none was a conflict git would
  have shown.
- A rule that belongs to every seat is now written eight times across the
  five skills, and the second decision prices that honestly as the cost of
  having no shared text. The decision's reopen condition names the guest
  paragraph as the first candidate for sharing, being five copies already.
- The runner pages of five skills move with this build, not three, because
  the guest paragraph sits in all five. What changes in a drawing is read
  off the seams, and a seam that touches five files owes five
  regenerations.

## Lacked

- No word in the skill for a drawing made twice: which parts of the first
  survive, and whether the record should say it was redrawn. I said so in
  the opening line, which is not a place the template has.
- Nothing about a pull request another session amends while the drawing
  is being made. The requirement moved by two criteria between the first
  drawing and this one, and the only signal was a comment.

## Longed for

- A mechanism for text shared between skills, so a paragraph five skills
  carry is written once. Every retro of mine on this task has asked for
  it, and this drawing's second decision says why.
