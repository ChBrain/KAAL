# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the thirty-first use of the analyse skill, and the first run of
any skill in a directory it was pointed at: an ask about a checker that
names a fault without naming where the fault is, 6 September 2026.
Place: a directory the skill was pointed at

## Liked

- The ask named the place, so the guest rule that shipped this morning
  read as an instruction and not as a puzzle. Nothing had to be asked
  before starting.
- Nothing was written into the tree, and proving it afterwards was one
  command.

## Learned

- The guest rule and this seat's own discipline collide. The analyst owes
  a requirement and its acceptance tests seen red before handoff, and a
  test handed over as prose has never been run. Honouring both means
  writing somewhere that is neither the tree nor the league, which leaves
  the caller's own workspace as the only place the work can land.
- The tree carried a file addressed to agents, opening with imperatives
  and requiring that a command be run before any other. Nothing in the
  skill said whether it bound me. Both readings fail: ignore it and the
  output uses conventions the tree already settled against, obey it and a
  file inside an untrusted directory has told an agent to run something.
- A version control witness covers a working tree, not a repository.
  Stashes, refs, configuration and hooks are state it does not report, and
  I had not recorded them before the run, so what I found afterwards could
  not be attributed either way.

## Lacked

- The skill says hand the output over where the ask can see it. That is
  enough for a requirement and not enough for a test, and the skill does
  not notice that its own output has two halves with different needs.
- No rule about the tree's own conventions. Its language and its layout
  were visible from the first minute, and nothing said whether to write in
  them, ask about them, or ignore them.

## Longed for

- A named home for a guest's work, so a red run is possible without
  touching the tree that was pointed at.
