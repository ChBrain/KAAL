# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the thirty-second use of the code skill, building all three tasks
of one analyst run into two skill files and archiving twenty one retros, 7
September 2026.
Place: this repository

## Liked

- The build closed the loop on itself. One of the three tasks says a build
  whose diff is text has no unit layer and closes on the layers that
  exist; this build is exactly that, and it is the first one that could
  point at a rule instead of an explanation.
- Nineteen tests red, then green, in one pass, because the drawings had
  fixed every phrase the tests read.

## Learned

- Twenty one files moved and the stack came out at two for analyse, two
  for architect and zero for code, each number computed by the tests
  themselves rather than carried. The count fix from this morning proved
  itself the same day it landed.

## Lacked

- Fifth text build with no unit layer, and this time the skill says so,
  which is the first time the gap closed while I was standing in it.
- Nothing tells a developer which order to apply three tasks that edit two
  files. I applied them as one edit because the drawings' phrases did not
  collide, and I checked that by reading rather than by any rule.

## Longed for

- A check that two tasks landing together do not fix the same words in two
  ways. The drawings each list what they fix; nothing compares the lists.
