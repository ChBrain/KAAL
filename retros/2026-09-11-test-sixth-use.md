# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the sixth use of the test skill, recording the run the fifth use could
not write, 11 September 2026.
Place: this repository

## Liked

- Writing the record was the thing that found the bugs. The fifth use refused
  it, three diffs cleared the way, and this one is the retest. Four seats and
  four lanes, and no seat argued about whose job it was, because each block
  said where and never what.
- Both records land green with nothing owed, and `the-test-tree-is-written-down`
  says `delivered` for the first time since the suite layer landed.

## Learned

- A record is a question the board otherwise stops asking. `not delivered` is
  a correct verdict and it is also a wall that has fallen silent about a task.
  A rule the developer deleted three days ago sat behind that silence, and so
  did twelve overtaken fixtures and a contract helper reading a report as a
  finding. None of the three was found by a wall; all three were found by
  trying to write one line of evidence.
- The ripple is not a curiosity any more, it is arithmetic. Three case reads
  cost three plan reads, `--write` advancing the pins cost the same three
  again, and the shas in the first pass were the shas before the write that
  cleared them. Nine reads to record two runs, and six of the nine say the
  same sentence about a reviews block nobody depends on.
- `kaal runs` says a word it has not earned. It reads records and never runs a
  suite, and it is called with one pass and no failures hard coded, so a task
  with no record reads `green, and no run has recorded it yet`. `push-v1`'s
  suite is red. The report is honest about the evidence and wrong in the one
  word a reader will carry away.

## Lacked

- A block that survives the diff that names it. Three were found today and all
  three lived in a retro until somebody read it, because the fifth kind of
  page is not built.

## Longed for

- A record that carries the block it waited on, so a green retest shows what
  was red and who cleared it, rather than only that it passes today.
