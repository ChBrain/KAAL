# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the sixty-eighth use of the analyse skill, specifying
`a-pin-says-who-cleared-it` after the league blocked on the thing it names,
10 September 2026.
Place: this repository

## Liked

- The ask had been carried for days as an open question and the tree answered
  it by stopping. Amending one criterion turned two walls red on a file the
  analyst may not touch, which is a better argument for this task than
  anything I could have written about it.
- Three of this league's own rules turn out to be incompatible, and saying so
  in one sentence made the criteria fall out. Main is always green, one pull
  request is one lane, one seat's act invalidates another seat's artefact.
  Any two hold. The requirement is what it costs to keep all three.
- Nothing here needed a new idea. A run record whose sha no longer matches
  counts as no record and the report says so; the coverage rows report and
  cannot refuse. A moved pin becoming a state with an owner is the third use
  of a shape this tree already had twice.

## Learned

- A sha computed in a test is a second opinion about what a region is, and
  the tool's is the one that counts. My first fixture hashed the criteria
  region by hand and lost the trailing newline, so a pin that should have
  read `current` read as moved and the test was red for its own defect. The
  fixtures let `--write` put the pin there now, and only then does the text
  move underneath it.
- A fixture is a tree before it is a fixture. Three cases were red on `no
trunk under kaal/` because a scratch tree with two directories is not a tree
  this league recognises, and that is a rule the task is not about. Every
  fixture carries a trunk now and none of them mentions it.
- I wrote a criterion that read the league's own tree for a state that moves.
  Criterion 6 asked whether the counts are on the line and looked at the 422
  pins here, which are all one state and will not stay that way. The skill
  says on fixed ground and I read past it because the real tree was the
  convenient one.
- A state nobody ever leaves is the vacuous pass wearing a state. The moment
  `review-needed` stops failing the board it has to cost something else, and
  the only honest place is the task: an unread pin belongs beside the run
  that has not happened, where the work is judged.

## Lacked

- No word for a tree that is honestly mid handoff. The board has green and
  red and the walls have three exit codes, and none of them says the tree is
  correct and incomplete at once. That is the whole of this task and I had to
  invent the phrase to write the goal.
- Nothing tells an analyst which drawings pin the criterion they are about to
  move. I found out by amending one and watching the board.

## Longed for

- The same answer for the plans count. A tool writing a number into the
  tester's directory is the first instance of this shape, the lane guard's
  drawing called it the weakest thing there, and it is still shared rather
  than solved.
- A way to ask a fixture whether it is a valid tree before asserting anything
  about it. Three of my six were red for a rule they were not testing, and a
  one line check at the top of a scratch tree would have said so.
