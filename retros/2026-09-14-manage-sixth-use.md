# Retrospective: 4 L's

Self-diagnosis: drawn from session context. Not a human-reported retro.

Period: the sixth use of the manage skill, re-evaluating 0.0.2 against the
objective rather than its promises and placing the remaining work,
14 September 2026.
Place: this repository

## Liked

- Running `a-seat-claims-what-it-covers` criterion 6 at both `2a28e09` and
  `9d24f0a` established the regression instead of asserting it, and it named
  the merge that introduced it without blaming the diff, which was clean.
- Asking two walls about one case turned a suspicion into a third disagreeing
  declaration of the topology, and it cost one command.
- The asker refusing the plan's own framing, that the three promises were the
  release, produced a better release than the plan had asked for.

## Learned

- A board, coverage rows and an open order were read off `main` and reported
  as current while `main` stood ninety eight commits behind `release`. The
  reading was internally consistent and wrong throughout, and nothing in it
  named the sha it was true of.
- A wall's verdict was reported from a summary line rather than from the lines
  under it, which is what the contract forbids, and the fuller capture said
  three cases where the summary had implied one.
- A plan named the mechanism for a block rather than the moment, which is the
  manager deciding what on behalf of two other seats. The rule against it is
  three lines above the item in the same file.
- A plan assigned a regression to a seat before the tester had recorded the
  bug that names the lane, which is the same error one step earlier.

## Lacked

- Four facts a session cannot start without: which remote target is
  authoritative, which sha the reading is against, whether this seat already
  has a lane open, and which of those is still unchecked.
- A declared contract for the board's own output, without which a clean single
  lane diff can break a case in another lane and no wall sees it.
- One answer to whether a case is blocked, rather than three surfaces
  answering differently.

## Longed for

- A manager view assembled from what each seat says it is blocked on, rather
  than from a board one seat happened to run.
- A cold start that reports an unknown as unknown, because a wrong answer
  stated plainly is acted on and a missing one is looked up.
